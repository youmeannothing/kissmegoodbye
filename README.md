# Kiss Me Goodbye — 조각글

발췌문과 조각글을 위한 작은 워드 프로세서.
종이에 바로 타이핑하고, 꾸민 모습 그대로 보관합니다.

**https://youmeannothing.github.io/kissmegoodbye/**

## 기능

- **텍스트 편집** — 종이 위에서 바로 쓰는 WYSIWYG. 굵게 / 기울임 / 밑줄 / 취소선 / 형광펜, 되돌리기·다시 실행, ⌘B·⌘I·⌘U 단축키
- **파일 삽입** — 이미지는 문서 안에 바로 삽입(자동 압축), `.txt`·`.md`는 커서 위치에 내용 삽입
- **저장** — ⌘S 또는 저장 버튼. 브라우저(localStorage) 보관함, 쓰다 만 글은 자동 임시 저장
  - 글 하나를 `.txt`로 내려받기
  - 전체를 `.json`으로 내보내기 / 가져오기 (백업·이사)

## 구조

정적 사이트. 서버 없음, 계정 없음 — 모든 글은 내 브라우저에만 있습니다.

- `index.html` — 마크업
- `style.css` — 콤팩트 에디토리얼 스타일 (Pretendard, 버건디 포인트)
- `app.js` — 에디터·보관함·저장 로직
