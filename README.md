# Kiss Me Goodbye — 조각글 서랍

발췌문과 조각글을 쓰고, 꾸미고, 보관하는 작은 에디터.
흘러가기 전에 문장을 붙잡아 둡니다.

**https://youmeannothing.github.io/kissmegoodbye/**

## 기능

- **텍스트 편집** — 굵게 / 기울임 / 밑줄 / 취소선 / 형광펜 툴바, 실시간 미리보기
- **파일 삽입** — 이미지 첨부(자동 압축), `.txt`·`.md` 파일은 커서 위치에 내용 삽입
- **저장** — 브라우저(localStorage)에 보관, 쓰다 만 글은 자동 임시 저장
  - 글 하나를 `.txt`로 내려받기
  - 전체를 `.json`으로 내보내기 / 가져오기 (백업·이사)

## 구조

정적 사이트. 서버 없음, 계정 없음 — 모든 글은 내 브라우저에만 있습니다.

- `index.html` — 마크업
- `style.css` — 콤팩트 에디토리얼 스타일 (Pretendard, 버건디 포인트)
- `app.js` — 에디터·보관함·저장 로직
